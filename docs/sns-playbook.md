## 1. 定位（所有內容嘅基調）

**SHOPOPS = 一隊軟件開發公司**（唔係齋 POS）。SNS 帳號代表**成間公司**。

- **做咩**：① 業務流程自動化　② 度身訂造軟件／系統　③ AI／數據分析
- **自家現成產品**：🍽️ ShopOps POS（餐廳點餐）／⭐ Reviewscope（評價監察）／🗓️ Rota（排班打卡）
- **最強賣點**：真生意日日用住磨出嚟（唔係 demo ware）＋ 零佣金、唔鎖數據、唔綁約
- **主要客群**：英國餐廳老闆 / 小生意（B2B）
- **網站**：shopops.co.uk

平台優先級：🥇 **LinkedIn**（B2B 接 project）→ 🥈 **Instagram + Facebook**（產品櫥窗）→ 🥉 TikTok（後備）

## 6. 執行貼士

- 🎬 **短片最值錢**：「離線斷網照落單」「QR → 廚房即彈」係天生 demo 素材，影一次剪幾段用成月
- 📌 **第一個月唔好硬賣**：先建立「識嘢、真做嘢」印象，賣嘢留後面
- 🔁 **一條內容三平台用**：IG 出 Reels、FB 出貼文、LinkedIn 改成 behind-the-scenes，慳力
- ⏰ **出 post 時間**：餐飲老闆下晝 2-4 點（午市後）或 晚上 9 點後（收工）先得閒碌手機
- 🖼️ **IG 一定要圖**（方形 1080×1080 最佳）；FB 可純文字 + 連結卡；IG 文字連結唔可撳 → 用 link in bio
